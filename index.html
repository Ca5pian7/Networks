1WHY SYNTRA EXISTS

Two problems, one connected fix

A user banned from one server can simply join the next. And members scattered across a hundred small communities have no way to talk to each other. Syntra solves both.

01 — SAFETY

Cross-server reporting

Mods file evidence-backed reports. A Review Team confirms and tiers them. Confirmed cases get broadcast to every partner server's mod-only alert channel — instantly.

  • Evidence required, not accusations
  • Two-reviewer confirmation before any broadcast
  • Every flagged user can appeal, from any server
02 — COMMUNITY

Global chat relay

Servers that opt in get a shared chat channel. Messages relay in real time, under each person's own name and avatar — not a bot's.

  • Opt-in per server, never forced
  • Local and network-wide mute controls
  • Auto-filtered for spam and invite links
2THE REPORT LINE

What happens after a report is filed

Every case follows the same track — nothing skips a stop.

STOP 1

A mod files a report

Evidence required — message links, screenshots, or a specific factual account. No evidence, no case.

STOP 2

Two reviewers confirm it

The case lands in a private hub, invisible to the public. At least two Review Team members independently confirm before anything moves further.

STOP 3

A tier gets assigned

Tier 1 stays logged. Tier 2 broadcasts network-wide. Tier 3 broadcasts and is also referred to Discord Trust & Safety directly.

STOP 4

Every partner server is alerted

A mod-only alert lands in every server's alert channel. Each server decides locally what to do — the network informs, it never overrides.

STOP 5 — OPTIONAL

The user appeals

From any partner server, or by DM. If upheld, a retraction broadcasts the same way the original alert did.

3SEVERITY SYSTEM

Not every report is treated the same

A tiered response keeps the network's alerts meaningful instead of noisy.

TIER 1

Logged only

Single unverified report, minor issue. Stored against the user ID. A second report later can bump it up automatically.

TIER 2

Network alert

Confirmed by two reviewers with solid evidence. Broadcast to every partner server's mod-only alert channel.

TIER 3

Severe / escalated

Credible threats, exploitation, doxxing. Broadcast network-wide and referred directly to Discord Trust & Safety or law enforcement.

4ON EVERY LINE

Everything a partner server gets

Not just alerts — a full moderation toolkit that comes with joining.

🚩

Reaction reporting

Any member can flag a message with one reaction. Mods accept, deny, or resolve with a reason — right from the alert.

🔤

Custom word filters

Each server bans its own words, censored automatically. Presets for common categories apply in one command.

🌐

Network-wide banned words

Serious terms are locked at the network level — no single server can quietly remove them.

📡

Live health monitor

A self-updating status panel any server can post — uptime, ping, and network stats refreshed automatically.

📢

Partnership ads

Recurring partnership posts targeted by server size, with automatic reposting on a schedule we set. Note it depends on server size — for more info contact staff.

⚖️

Appeals from anywhere

A flagged user can appeal from any partner server or by DM — reviewed like a private mod-mail thread.
