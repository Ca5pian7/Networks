1BEFORE YOU START

What you'll need

Nothing complicated — just server admin access and a few minutes. Here's what's helpful to know going in:

  • You'll need Manage Server permission (or Administrator) to run setup commands.
  • The bot needs to create/manage a couple of channels — make sure you're comfortable granting it Manage Channels and Manage Webhooks during the invite step.
  • Read the Partner Charter first if you haven't — it explains exactly what joining means, including what data gets shared network-wide.
Your server keeps full autonomy. Joining the network doesn't hand over moderation control — it just connects your alert channel to the network and lets your mods file/receive reports. You decide what to do with any alert you receive.
2INVITE THE BOT

Add Tunnel Bot to your server

Click the invite button on the network homepage, or use the link directly. Choose your server from the dropdown, and approve the requested permissions — these are all needed for the bot's actual features (message management for filters, webhooks for global chat, reactions for the report button).

3CREATE YOUR CHANNELS

Set up two or three channels

You only need channels for the features you actually want to use. At minimum, create one mod-only channel for alerts.

ChannelVisibilityPurpose
#network-alertsMods onlyRequired — receives network-wide safety alerts
#mod-logMods onlyOptional — local reaction-reports and word filter hits land here
#global-chatPublicOptional — only if you want cross-server chat
#partner-adsPublic or staffOptional — only if you want to receive partnership ads
4RUN THE SETUP COMMANDS

Register your channels

Run each command inside the channel you want it tied to — the bot registers whichever channel you're in when you run the command.

Required

/setup alerts_channel

Run this in your mod-only alert channel. This is the only truly required step — everything else is optional.

Optional, but recommended

/setup modlog_channel

Run this in your mod-log channel. Without it, reaction-reports and word filter alerts fall back to your alerts channel.

Only if you want global chat

/setup global_channel

Run this in your public chat channel. The bot needs Manage Webhooks here — it creates a webhook automatically to relay messages under each person's real name and avatar.

Only if you want partnership ads

/setup ads_channel
5APPOINT YOUR LIAISON

One point of contact

/setup liaison

Run this to register yourself, or mention someone else: /setup liaison user:@SomeMod. Your Liaison is the person responsible for watching alerts and being the network's point of contact for your server.

7FAQ

Common questions

Do I have to enable global chat?

No — every feature beyond the alert channel is opt-in. Skip any /setup command for a feature you don't want.

Can I leave the network later?

Yes, anytime — just remove the bot from your server. No penalty, no lock-in.

Who sees my reports?

Only the Review Team, in the private hub. Nothing is public until a case is confirmed and broadcast.

What if a report about my server is wrong?

Use /appeal — it works from any partner server and starts a private review with the team.

Still stuck? Reach out to whoever invited you to the network, or check the Partner Charter and Privacy Policy & Terms for anything not covered here.
